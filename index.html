Mapa mental del capítulo

El capítulo prepara la notación que después se usa en regresión lineal matricial.

1. Vectores aleatorios

Pasamos de variables individuales a vectores: $\mathbf X=(X_1,\ldots,X_n)'$.

2. Esperanza

La esperanza de una matriz o vector se calcula entrada por entrada.

3. Covarianza

La covarianza se vuelve una matriz con todas las covarianzas cruzadas.

4. Transformaciones

Si multiplicas por matrices constantes, la esperanza y varianza se transforman ordenadamente.

5. Formas cuadráticas

Expresiones como $\mathbf X' A \mathbf X$ serán esenciales para sumas de cuadrados y pruebas.

6. Regresión

Luego aparecerá $Y=X\beta+\varepsilon$, y estas reglas serán la base de casi todo.

Definiciones base

Vector aleatorioEsperanzaCovarianzaMatriz de varianza

Vector aleatorio

Un vector aleatorio es un vector cuyas componentes son variables aleatorias. Antes de observar los datos, sus valores pueden cambiar de una muestra a otra.

$$\mathbf X=\begin{pmatrix}X_1\\X_2\\\vdots\\X_n\end{pmatrix}$$

Esperanza de una matriz aleatoria

Si $\mathbf Z=(Z_{ij})$, entonces:

$$E[\mathbf Z]=(E[Z_{ij}])$$

Covarianza entre vectores

Si $\mathbf X$ tiene $m$ componentes y $\mathbf Y$ tiene $n$ componentes:

$$\operatorname{Cov}(\mathbf X,\mathbf Y)=(\operatorname{cov}(X_i,Y_j))$$
Regla para recordar: si algo es constante, la esperanza no lo promedia; si algo es aleatorio, sí.

Teorema 1: esperanza del sándwich matricial

Si $A$, $B$ y $C$ son matrices constantes, entonces:

$$E[A Z B+C]=A E[Z]B+C$$
Idea clave: la esperanza no toca constantes; solo promedia lo aleatorio.

Demostración paso a paso

Paso 1. Define $W=AZB+C$.
Paso 2. Mira la entrada $(i,j)$: $$W_{ij}=\sum_r\sum_s a_{ir}Z_{rs}b_{sj}+c_{ij}.$$
Paso 3. Aplica esperanza: $$E[W_{ij}]=\sum_r\sum_s a_{ir}E[Z_{rs}]b_{sj}+c_{ij}.$$
Paso 4. Esa entrada es exactamente la entrada $(i,j)$ de $AE[Z]B+C$.
Analogía para memorizar

$A$ y $B$ son el pan del sándwich. $Z$ es el relleno aleatorio. $C$ es la salsa. La esperanza cambia el relleno por su promedio, pero deja el pan y la salsa igual.

Teorema 2: covarianza como producto de desviaciones

Si $E[X]=\alpha$ y $E[Y]=\beta$, entonces:

$$\operatorname{Cov}(X,Y)=E[(X-\alpha)(Y-\beta)']$$
Idea clave: covarianza = promedio de productos de desviaciones.

Demostración paso a paso

Paso 1. Por definición, $\operatorname{Cov}(X,Y)=(\operatorname{cov}(X_i,Y_j))$.
Paso 2. Cada entrada cumple: $$\operatorname{cov}(X_i,Y_j)=E[(X_i-\alpha_i)(Y_j-\beta_j)].$$
Paso 3. El producto $(X-\alpha)(Y-\beta)'$ produce una matriz con todas esas entradas.
Paso 4. Al aplicar esperanza entrada por entrada, aparece la matriz de covarianzas.
Ejemplo 2x2
$$E[(X-\alpha)(Y-\beta)']=\begin{pmatrix}\operatorname{cov}(X_1,Y_1)&\operatorname{cov}(X_1,Y_2)\\\operatorname{cov}(X_2,Y_1)&\operatorname{cov}(X_2,Y_2)\end{pmatrix}$$

Teorema 3: covarianza bajo transformaciones lineales

Si $A$ y $B$ son matrices constantes:

$$\operatorname{Cov}(AX,BY)=A\operatorname{Cov}(X,Y)B'$$

Lectura

Cuando transformas $X$ e $Y$ linealmente, la matriz de covarianza se transforma con esas mismas matrices constantes.

Demostración paso a paso

Paso 1. Define $U=AX$ y $V=BY$.
Paso 2. Usa el teorema anterior: $$\operatorname{Cov}(U,V)=E[(U-E[U])(V-E[V])'].$$
Paso 3. Como $E[AX]=AE[X]=A\alpha$ y $E[BY]=B\beta$, queda: $U-E[U]=A(X-\alpha)$ y $V-E[V]=B(Y-\beta)$.
Paso 4. Sustituye: $$E[A(X-\alpha)(Y-\beta)'B'].$$
Paso 5. Como $A$ y $B'$ son constantes, salen: $$A E[(X-\alpha)(Y-\beta)']B'=A\operatorname{Cov}(X,Y)B'.$$
Caso especial: $$\operatorname{Var}(AX)=A\operatorname{Var}(X)A'$$

Teorema 4: cuándo la matriz de varianza es positiva definida

Si ningún elemento de $X$ es combinación lineal de los demás, entonces $\operatorname{Var}(X)$ es positiva definida.

$$c'\operatorname{Var}(X)c=\operatorname{var}(c'X)$$

Demostración paso a paso

Paso 1. Toma cualquier vector constante $c$.
Paso 2. La cantidad $c'X$ es una variable aleatoria que mezcla linealmente los componentes de $X$.
Paso 3. Por la regla de varianza: $$\operatorname{var}(c'X)=c'\operatorname{Var}(X)c.$$
Paso 4. Una varianza no puede ser negativa.
Paso 5. Si fuera cero con $c\neq0$, entonces $c'X$ sería constante. Eso implicaría una relación lineal exacta entre componentes de $X$, justo lo que se descartó.
Conclusión: para todo $c\neq0$, $c'\operatorname{Var}(X)c>0$, por lo tanto la matriz es positiva definida.

Teorema 5: esperanza de una forma cuadrática

Sea $X$ un vector aleatorio, $A$ una matriz simétrica, $E[X]=\mu$ y $\operatorname{Var}(X)=\Sigma$. Entonces:

$$E[X'AX]=\operatorname{tr}(A\Sigma)+\mu'A\mu$$

Interpretación

Una forma cuadrática mide una suma ponderada de cuadrados y productos cruzados. En regresión aparecen constantemente en sumas de cuadrados.

Demostración paso a paso

Paso 1. Como $X'AX$ es un escalar, se puede escribir como su traza: $$X'AX=\operatorname{tr}(X'AX).$$
Paso 2. Usa propiedad de la traza: $$\operatorname{tr}(X'AX)=\operatorname{tr}(AXX').$$
Paso 3. Aplica esperanza: $$E[X'AX]=\operatorname{tr}(A E[XX']).$$
Paso 4. Usa la identidad: $$\operatorname{Var}(X)=E[XX']-\mu\mu'$$ por lo tanto $$E[XX']=\Sigma+\mu\mu'.$$
Paso 5. Sustituye: $$\operatorname{tr}(A(\Sigma+\mu\mu'))=\operatorname{tr}(A\Sigma)+\operatorname{tr}(A\mu\mu').$$
Paso 6. Como $\operatorname{tr}(A\mu\mu')=\mu'A\mu$, queda la fórmula final.

Teorema 6: varianza de una forma cuadrática

Este resultado es más técnico. Sirve para calcular la variabilidad de $X'AX$ cuando las variables son independientes y tienen momentos comunes.

$$\operatorname{var}(X'AX)=E[(X'AX)^2]-\{E[X'AX]\}^2$$

Idea de la demostración

Paso 1. Centra el vector: escribe $Y=X-\theta$. Así separas media y variabilidad.
Paso 2. Expande: $$X'AX=(X-\theta)'A(X-\theta)+2\theta'A(X-\theta)+\theta'A\theta.$$
Paso 3. Eleva al cuadrado y calcula esperanza término a término.
Paso 4. Usa independencia: muchos productos tienen esperanza cero; sobreviven los términos con momentos de orden 2, 3 y 4.
Paso 5. Agrupa con trazas y diagonales de $A$.
Resultado general: $$\operatorname{var}(X'AX)=(\mu_4-3\mu_2^2)a'a+2\mu_2^2\operatorname{tr}(A^2)+4\mu_2\theta'A^2\theta+4\mu_3\theta'Aa$$

Aquí $a$ es el vector de elementos diagonales de $A$. La fórmula completa es avanzada; lo importante es reconocer que usa momentos centrales de orden 2, 3 y 4.
