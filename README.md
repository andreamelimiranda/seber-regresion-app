# Seber Regresión App

Aplicación web didáctica para estudiar análisis de regresión usando como base el capítulo 1 de Seber & Lee: vectores de variables aleatorias, esperanza, covarianza, matrices de varianza y formas cuadráticas.

## Contenido

- Explicación paso a paso de los teoremas principales del capítulo 1.
- Demostraciones guiadas.
- Analogías para memorizar.
- Flashcards.
- Quiz interactivo.
- Calculadora simple para practicar linealidad de la esperanza.

## Importante

Esta app no sube archivos PDF ni material pesado. Solo contiene HTML, CSS y JavaScript liviano.
