# Seber Regresión App

Aplicación didáctica e instalable para estudiar análisis de regresión usando como base el capítulo 1 de Seber & Lee: vectores de variables aleatorias, esperanza, covarianza, matrices de varianza y formas cuadráticas.

## Enlace público

https://andreamelimiranda.github.io/seber-regresion-app/

## Cómo instalar en el celular

### Android / Chrome

1. Abre el enlace público en Chrome.
2. Si aparece el botón **Instalar app**, presiónalo.
3. Si no aparece, toca los tres puntos del navegador y selecciona **Agregar a pantalla principal**.

### iPhone / Safari

1. Abre el enlace público en Safari.
2. Toca el botón de compartir.
3. Elige **Agregar a pantalla de inicio**.

## Contenido

- Explicación paso a paso de teoremas principales del capítulo.
- Demostraciones guiadas.
- Analogías para memorizar.
- Flashcards.
- Quiz interactivo.
- Calculadora simple de covarianza muestral.

## Importante

Esta app no sube archivos PDF ni material pesado. Solo contiene HTML, CSS, JavaScript, manifest, service worker e ícono SVG liviano para que funcione como PWA.
